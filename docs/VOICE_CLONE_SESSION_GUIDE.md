# 🎙️ Session ក្លូនសំឡេងតួ — របៀបប្រើ

**គោលការណ៍៖ ១ តួ = ១ សំឡេង។** Upload សំឡេងម្តងនៅលើតួ ហើយឃ្លាទាំងអស់របស់តួនោះនឹងប្រើសំឡេងដដែល — សំឡេងមិនប្ដូរពីឃ្លាមួយទៅឃ្លាមួយទេ។

បើកកម្មវិធី → Sidebar ខាងឆ្វេង → **Session ថ្មី** (ទំព័រនេះបើកមុនគេដោយស្វ័យប្រវត្តិ)។

## សញ្ញានៅលើឃ្លានីមួយៗ

- 🔵 **ប្រុស ១** / 🌸 **ស្រី ១** — តួដែលនិយាយឃ្លានោះ (ពណ៌ខៀវ = ប្រុស, ពណ៌ផ្កាឈូក = ស្រី)
- **⬆ Upload សំឡេង ប្រុស ១** (ពណ៌ទឹកក្រូច) — តួនោះ **មិនទាន់មានសំឡេង**។ ចុចលើវាដើម្បី Upload ភ្លាមៗ
- **✓ សំឡេង ប្រុស ១** (ពណ៌បៃតង) — ឃ្លានេះនឹងប្រើសំឡេងរបស់តួនោះ
- ▶ — ស្ដាប់សំឡេងឃ្លានោះ (បង្ហាញក្រោយបង្កើតរួច)

ឧទាហរណ៍៖ បើ **ប្រុស ១** មាន ៣ ឃ្លា → Upload សំឡេង **តែម្តង** → ឃ្លាទាំង ៣ ប្រើសំឡេងដូចគ្នាដោយស្វ័យប្រវត្តិ។

## គន្លឹះសំឡេងល្អ (សំខាន់!)

1. **ប្រវែង ១០–៣០ វិនាទី** (ប្រព័ន្ធប្រើតែ ៣០ វិនាទីដំបូង)
2. **សំឡេងស្អាត** — គ្មានភ្លេង គ្មានសំឡេងរំខាន មនុស្សតែម្នាក់និយាយ
3. និយាយ **ធម្មជាតិ** ដូចតួក្នុងរឿង
4. ឯកសារទទួលយក៖ `.mp3 .wav .m4a .aac .ogg .flac .webm` ឬវីដេអូខ្លី `.mp4` (អតិបរមា 50MB)

## មុខងារបន្ថែម (ធ្វើដោយដៃ)

- **ចុចលើឈ្មោះតួ** ឬ Tab ខាងលើបញ្ជីឃ្លា → បង្ហាញតែឃ្លារបស់តួនោះ
- **✏️ កែអត្ថបទ** — ចុចរូបខ្មៅដៃក្បែរឃ្លា → កែ → Enter ដើម្បីរក្សាទុក
- **ប្ដូរភេទតួ** (ប្រុស/ស្រី) — បើ AI ច្រឡំ ចុចប្ដូរនៅខាងក្រោមកាតតួ
- **ប្ដូរសំឡេង** / 🗑️ **លុប** — នៅលើកាតតួដែលមានសំឡេងរួច
- **ឬជ្រើសសំឡេងពីបណ្ណាល័យ…** — បើគ្មានឯកសារសំឡេងផ្ទាល់ខ្លួន អាចជ្រើសសំឡេងដែលមានស្រាប់

> តួដែលមិនបាន Upload សំឡេង នឹងប្រើ **សំឡេងលំនាំដើម** (ដូចគ្នាគ្រប់ឃ្លារបស់តួនោះ)។

## មុខងារ AUTO ត្រូវបានលាក់

ដើម្បីកុំឲ្យច្រឡំ មុខងារស្វ័យប្រវត្តិ (ឧ. **AI TTS ខ្មែរ AUTO**, **TURBO**) ត្រូវបានលាក់តាមលំនាំដើម។
បើចង់ប្រើវិញ៖ Sidebar → **បង្ហាញ AUTO** (ចុចម្តងទៀតដើម្បីលាក់)។

ការងារលម្អិត (Timeline, Effects, Subtitle) នៅតែប្រើបានក្នុង **វីដេអូ (Studio)** ឬប៊ូតុង
“បើកស្ទូឌីយោកម្រិតខ្ពស់” នៅខាងក្រោមទំព័រ Session។
